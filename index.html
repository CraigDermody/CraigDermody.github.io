Research and Reports

This page is an archive of reports produced by or in partnership with Creative Sonoma.* Click on the headline of each item to learn more.

Option 1: Combined / Interactive

Creative Sonoma Impact Dashboard

This version shows grants, awards, recipients, and event attendance together in one interactive view. Visitors can use drop-down filters to explore the grant information, though the event attendance number stays unchanged because it comes from a separate dataset. This option works well for internal review, but may need explanation for public audiences.

Option 2: Separated / Interactive

Creative Sonoma Impact Dashboard

This version separates grant information from event attendance and lets visitors switch between views. Each view has filters that apply only to the information on that screen, which can make the experience clearer for public users. The tradeoff is that it is less useful as an at-a-glance internal dashboard because not everything is visible at once.

Option 3: Combined / Simplified

Creative Sonoma Impact Dashboard

This version presents the key information together in a simpler, website-friendly format without drop-down filters or extra dashboard framing. It is a strong option for public viewing because it is easy to scan and requires little instruction. Internal users may find it less flexible because they cannot filter or drill into the information as much.

Option 4: Separated / Simplified

Creative Sonoma Impact Dashboard

This version splits the information into two focused dashboard areas with explanatory text around each one. It gives public visitors a clearer path through the grant and event information, and it leaves room for more detail without making one dashboard feel crowded. Because it is less interactive and separates the content, it is the least suited for internal KPI monitoring.
